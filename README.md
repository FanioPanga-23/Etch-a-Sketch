# Etch-a-Sketch

A browser-based drawing toy inspired by the classic Etch A Sketch. This project creates an interactive grid where users can draw by hovering over cells, choose colors, and reset the board.

## Solution
- HTML for layout and controls
- CSS for styling and responsive grid behavior
- JavaScript for grid creation, drawing interaction, color selection, and reset functionality

## How to use
1. Open `index.html` in a web browser.
2. Use the color picker or default black to draw.
3. Hover over grid cells to create strokes.
4. Click the reset button to clear the board and start again.

## Files
- `index.html` — page structure and controls
- `index.css` — visual styling
- `js/javaScript.js` — interactive drawing logic
